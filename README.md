# AA 漫畫翻譯輔助工具 — 使用說明

請點擊aa_main_qt.exe開始使用
編輯器中字體寬度有問題的話，請按Ctrl+F改字型看看
—

## 基本工作流程

1. 貼上或從網址讀取日文原文
2. 點「提取日文」，取出需翻譯的文字
3. 將提取結果進行翻譯(AI、手動皆可)
4. 將翻譯貼回「填入翻譯」區
5. 點「替換翻譯並編輯」，進入編輯器微調後儲存

### 提取區

#### ⬇️ 提取日文 ⬇️


點擊後系統分析原始文本，過濾掉 AA 圖形，提取出需要翻譯的純文字片段，以 `001-1|日文` 格式顯示於「提取結果」區。

### 關於「原文比對」（Alt+2）

按 `Alt+2` 可切換至原文比對模式，左側顯示翻譯後內容、右側顯示翻譯前的日文原文，方便對照確認。

**原文是「按下翻譯按鈕當下，原始文本欄的內容」**，系統會自動儲存，下次開啟同一份 HTML 時仍可使用。

原文在以下時機寫入：

| 時機 | 說明 |
|------|------|
| 按「🚀 替換翻譯並編輯」 | 進入編輯器時自動儲存 |
| 按「💾 替換翻譯並儲存」 | 存檔完成時自動儲存 |
| 在編輯器中按 `Ctrl+S` 或「💾 儲存」 | 存檔時自動儲存 |

原文以「投稿標頭指紋」（原文第一則貼文的日期＋時間＋作者 ID）為索引，存放於 `aa_original_cache.json`。下次用「打開已儲存的 HTML」或從批次搜尋開啟同一份檔案時，系統會自動載入對應的原文供比對。
因為索引改用指紋而非檔名，**改了 HTML 檔名後原文比對仍能正常命中**（舊版以檔名為索引的紀錄也相容）。
儲存的原文上限可至設定中調整

### 關於「用語集」（Alt+5）

按 `Alt+5` 可在編輯器右側展開用語集面板，直接在編輯器內檢視與編輯一般術語表，與主畫面雙向即時同步。面板內有搜尋框，寬度可調整並持久化。

| 按鈕 | 說明 |
|------|------|
| 💾 儲存用語 | 只把術語寫入設定檔（不動過濾規則等其他設定）；左鍵依「僅合併差異」設定、右鍵強制覆蓋 |

---

### 關於「局部重套用」（Alt+4）

按 `Alt+4` 可在編輯器右側展開局部重套用面板，面板內包含「提取結果」與「填入翻譯」兩個文字區。

**用途**：翻譯完後才發現某段提取或翻譯有誤，不想重跑整個流程時使用。

**操作流程**：
1. 在編輯器中捲動到**已確認不需要修改的最後一行**，讓該行出現在可視範圍內
2. 在編輯器中**框選**你想修改的那一行（或該行內任意片段）
3. 按 `Alt+4` 展開面板 — 該行對應的提取／翻譯列會自動在面板中整列選取並置中，方便直接覆蓋
4. 在面板中修改「提取結果」或「填入翻譯」
5. 按「重新套用」

系統會**只覆蓋目前可視行以下**的內容，可視行以上的部分（你已手動微調過的段落）會完整保留。

> 註：Alt+4 只在「有框選」時對齊面板；只把游標點在某行（沒框選）按 Alt+4 不會跳行。
> 若想沿用前一次面板已對齊的位置，可以不框選直接按 Alt+4。

**自動捲動（面板上方勾選框）**：勾選後，讓你在編輯器中操作時面板自動跟進：
- 在編輯器中**重新框選**一段文字 → 面板自動把對應行整列選取＋置中
- 編輯器**捲動且當前無框選** → 面板會跟著捲到編輯器可視中心行對應的列
- 編輯器**有框選時捲動** → 面板**不**跟動，避免把你剛剛對齊的選取捲走

未勾選時，面板完全靜止，只有手動按 Alt+4 才會對齊。

面板中的提取結果與翻譯預設從主畫面同步，也可以直接在面板內手動修改後套用。

## 自動翻譯

點工具列「⚡ 自動翻譯」開啟。設定起始網址與話數後，程式會自動完成「抓取 → 提取 → 翻譯 → 替換 → 存檔 → 下一話」整個流程，翻完後的 HTML 直接存到指定資料夾。

| 欄位 / 按鈕 | 說明 |
|-------------|------|
| 起始網址 | 第一話的網頁網址 |
| 話數 | 要翻幾話（0 = 翻到最後一話） |
| 作品名稱 | 用於產生輸出檔名 |
| 翻譯方式 | 瀏覽器（操控網頁版 Gemini）或 API（直接呼叫 Gemini API）|
| 輸出資料夾 | 存檔位置 |
| ⚙ 連線設定 | 設定 Gem 網址、要求模型、每 N 次換新對話、API 金鑰與翻譯 Prompt |
| ■ 停止 | 隨時中止（翻完的話皆已存檔） |

**使用 API 模式**：需要 Gemini API 金鑰，在「連線設定」中填入（以 Windows DPAPI 加密存於本機，不會上傳）。

**使用瀏覽器模式**：需安裝 Playwright（`pip install playwright` 後執行 `playwright install chromium`）。

## 批次搜尋

點工具列「批次搜尋」開啟。可在指定資料夾內的所有 HTML 中搜尋關鍵字或正則表達式，並進行批次取代。

| 功能 | 說明 |
|------|------|
| 搜尋 | 在資料夾所有 HTML 的內文中搜尋，最多顯示 500 筆結果 |
| 替換（單筆） | 對單一結果執行取代 |
| 全部替換 | 對所有搜尋結果執行批次取代 |
| 全部復原 | 將本次批次替換涉及的所有檔案一次還原 |
| 復原（單筆） | 還原單一檔案的修改 |
| ✕（排除） | 將某筆結果從批次取代範圍中移除 |
| 開啟 | 在編輯器中開啟該檔案，並跳至對應行 |
| 快速替換面板（右側） | 輸入 `A=B`，點 `[→]` 按鈕快速填入搜尋 / 替換欄；雙擊可加入主術語表 |

## 設定（⚙）內容說明

| 選項 | 說明 |
|------|------|
| 提取日文後自動複製到剪貼簿 | 每次點「提取日文」後自動複製提取結果 |
| 韓文提取模式 | 開啟後「提取」改用韓文字元集（Hangul），略過日文 `base_regex`，其餘流程不變 |
| 🧪 實驗性日文提取演算法 | 開啟後改走「錨點掃描＋分數制過濾」新路徑，減少 AA 圖中夾雜少量合法字元被誤抓的情況；關閉則走原本演算法（韓文模式不受影響） |
| 🧪 替換翻譯時：偵測文字右側 AA 圖並補全形空白 | 開啟後，若被替換文字的右側殘留內容像 AA 圖，會盡量讓右側 AA 維持原位置：譯文較短→補全形空白；譯文較長→吃掉右側多餘空白。關閉（預設）僅在右側出現對話框邊框字元時才補空白 |
| 批次搜尋：點擊術語按鈕時自動搜尋 | 在批次搜尋中點術語按鈕時是否自動觸發搜尋 |
| 套用翻譯時：術語表只套用於譯文部分 | 開啟後術語表僅套用於 AI 翻譯文，原文中未提取的區域（AA 圖、空行等）不再被全域替換 |
| 套用術語表時：平假名／片假名互通 | 開啟後術語原文的平假名與片假名視為相通（例如「ライザ=萊莎」同時匹配「らいざ」），預設關閉 |
| 存入術語後自動儲存到設定檔 | 開啟後每次「存入術語」時自動寫入 `AA_Settings.json`，不必再手動儲存設定；預設關閉 |
| 儲存設定時僅合併差異 | 開啟後按「儲存設定」只寫入新增或修改的項目，刪掉的術語不會從 `AA_Settings.json` 中移除 |
| 進入編輯器時預設開啟「所見即所得」模式 | 每次進入編輯器時自動套用 Alt+3 WYSIWYG 模式 |
| 另存新檔時內嵌字型 | 開啟後，另存新檔時會把選定的 AA 字型以 Base64 內嵌到 `<head>` 的 `@font-face`，產出的 HTML 單一檔案即可在手機等環境正確顯示 AA 圖形，無需外部字型檔（Ctrl+S 覆蓋現有檔案時不內嵌） |
| 字型選擇下拉 | 選擇要內嵌的字型：Monapo（+3.5 MB）、Saitamaar（+2.7 MB）、textar（+4.3 MB）；啟用「另存新檔時內嵌字型」後才可選 |
| 作者名稱歷史記錄數量 | 主畫面🕘按鈕的歷史筆數上限 |
| 清除網址紀錄時保留筆數＋清除紀錄按鈕 | 網址讀取紀錄本身已無上限；點「清除紀錄」時依此值保留最新 N 筆（0 = 全清） |
| 抓網頁 Proxy | 抓取 AA 故事網頁（含自動翻譯抓下一話、網址讀取）時使用的代理伺服器；留空＝直連（沿用 Windows 系統設定）。設定後立即生效，不必重開程式 |
| API 翻譯 Proxy | 自動翻譯 API 模式呼叫供應商端點時使用的代理伺服器；留空＝直連。與上面分開是因為 API 端點若本來就連得上，直連通常比走代理快 |
| 原文暫存儲存數量 | `aa_original_cache.json` 儲存的原文份數上限 |
| 清除暫存 | 清空 `aa_original_cache.json` |
| 設定資料夾＋開啟按鈕 | 顯示所有設定實際存放的位置（`%APPDATA%\AATool\`）；「開啟」以檔案總管打開 |
| 匯入舊版設定 | 選擇舊版的程式資料夾（或另一台電腦備份下來的 `AATool` 資料夾），把設定繼承過來並立即套用；覆蓋前會自動留一份 `.before-import` 備份 |

**什麼時候需要填 Proxy**：如果某個網址**用瀏覽器打得開、本程式卻抓不到**（跳 TLS 握手逾時、連線被拒絕之類的錯誤），通常是因為代理只掛在瀏覽器上（擴充功能或 PAC），本程式走的是直連。這時在「抓網頁 Proxy」填入你代理工具的本機位址即可，例如 Clash 預設的 `127.0.0.1:7890` 或 v2rayN 的 `127.0.0.1:10809`（可以只填 `位址:埠號`，程式會自動補上 `http://`）。抓取失敗時程式會自動診斷並在訊息中指出可能原因，可先照上面的建議處理。

## 資料保存說明

所有設定都存放在**設定資料夾**：`%APPDATA%\AATool\`（可在 ⚙ 全域設定最下方看到實際路徑，按「開啟」直接用檔案總管打開）。

放在這裡的好處是**更新程式不會弄丟設定**——覆蓋 exe 或重新解壓到新資料夾都不影響；要備份或換電腦，複製這一個資料夾即可。從舊版更新上來時，程式第一次啟動會自動把原本留在程式資料夾裡的設定複製過來，不需要任何操作（原檔會保留）。

| 檔案 | 用途 |
|------|------|
| `AA_Settings.json` | 過濾規則與術語表（手動讀取 / 儲存） |
| `aa_settings_cache.json` | 程式狀態暫存（每次輸入後自動儲存，關閉重開不丟失） |
| `aa_api_keys.dat` | 自動翻譯的 API 金鑰（以 Windows DPAPI 加密，換電腦或換使用者帳號無法解密） |
| `aa_original_cache.json` | 原文暫存（用於編輯器中的原文比對功能） |
| `aa_api_quota.json` | Gemini 每日配額的冷卻狀態 |
| `aa_crash.log` | 程式異常時的錯誤記錄 |
